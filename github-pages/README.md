# WorkLanceo on GitHub Pages

Build from the project root with `node scripts/build-github-pages.mjs`.
Copy only the generated contents of `work/pages-build/` into `worklanceo/` in the repository serving shambhavaa.com. Do not replace the root CNAME or existing Shambhavaa files.

Public pages, solution details and calculators run under `/worklanceo/`. Hiring enquiries, sign-in, workspace and admin links open the existing server-backed site at https://kaamsetu-workforce.diprish.chatgpt.site. This preserves the database, file storage and access checks. GitHub Pages does not store form submissions. No customer records or credentials belong in this repository.

The logo is the original image supplied by the business owner.
